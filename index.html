Navy SwitchPro

Instalador de firmware para el controlador ESP32

Tu navegador no soporta Web Serial. Usa Chrome, Edge u Opera. Esta página necesita HTTPS para poder conectarse al ESP32.

Antes de instalar:

  • Usa Chrome, Edge u Opera (de escritorio).
  • Conecta el ESP32 por USB antes de apretar el botón.
  • Si no aparece el puerto, instala el driver de tu chip USB-serie (CP2102 o CH340, según tu placa).

Mejoras version 1.0.0:

  • Version Inicial del binario.
  • Se puede invertir los ejes XY de los joysticks, es decir, cuando presionabas hacia arriba se detectaba que iba hacia abajo y viceversa, lo mismo con derecha e izquierda.
  • Para invertir los ejes.
  • Plus + X -> invierte el eje X del stick IZQUIERDO
  • Plus + Y -> invierte el eje Y del stick IZQUIERDO
  • Plus + A -> invierte el eje X del stick DERECHO
  • Plus + B -> invierte el eje Y del stick DERECHO
  • Cada combinacion actua UNA vez por pulsacion (no hace falta soltar y volver a presionar rapido; con mantenerlos juntos un instante alcanza, no sigue alternando mientras los mantengas apretados).

Mejoras version 1.0.1:

  • Se desactiva el boton fisico para Captura.
  • Se activa a un pin funcional el boton L3 (antes no funcionaba).
  • Se agrega combinacion Boton Plus (+) y L3 para activar la captura.
  • Se puede calibrar el rango fisico del Joystick, (cuando no alcanza a llegar a la orilla en la pantalla de calibracion). La forma de calibrarlo es: Se mantiene el stick al fondo de esa direccion (UDLR), y presionando el boton + y el DPad en esa direccion (la misma que el stick), se tomara como valor maximo y se autocalibrara. Repetir los pasos para el stick Derecho, pero esta vez usando el boton Menos (-). .
